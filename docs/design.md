# LinguaLens 界面约束

用户已选择“跟随浏览器：浅色简洁、蓝色主按钮”。这里采用浏览器原生控件习惯与浅色界面；本版本没有独立的深色主题。

设置页的主任务是填写模型连接并保存，侧栏只承载配置切换。弹窗优先显示当前模型、目标语言与翻译动作。使用系统字体、白色表面、灰色边界和蓝色主按钮，避免装饰影响表单阅读。

首次进入轻微上移淡入；主按钮按压提供反馈；保存与错误提示从原位置淡入。尊重 `prefers-reduced-motion`。页面文本在翻译期间降低透明度，失败段落使用虚线标记，原始页面标签和事件处理器保持不变。

验收覆盖 380px 弹窗、宽屏和窄屏设置页、200% 阅读尺寸、脱敏密钥、多配置切换、错误提示、保存后重读与单段重试。实际证据和完成状态见 `verification.md`。
